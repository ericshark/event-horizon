## Checks

Final full-suite result: **48 passed (3.3 minutes)** across desktop and mobile, including retained legacy regressions and both real-time round-trip recordings.

- `npm run build`: passed (includes TypeScript checking). Vite reports its existing large-chunk warning; current JS bundle is approximately 686 kB before gzip.
- Prettier check across changed source, markup, CSS and tests: passed.
- `git diff --check`: passed.
- Impeccable detector: one static `flat-type-hierarchy` warning on HTML, which does not resolve the external stylesheet. Rendered headings are visibly larger than body copy (desktop 46–52 px versus 13–14 px; mobile 28 px versus 11 px).

Browser: Google Chrome for Testing 156.0.8078.4, headless on Linux with ANGLE SwiftShader. Main viewports: 1440×1000 and 390×844; resize case: 1366×768. Tests use the cached Chromium binary through `CHROMIUM_PATH`, since `/usr/bin/chromium` is absent.

```bash
PW_HEADLESS=true CHROMIUM_PATH=/home/eric/.cache/ms-playwright/chromium-1248/chrome-linux64/chrome npm test
```

Functional and visual verification uses software rendering. Real GPU frame pacing and physical mobile hardware performance were not measured; these recordings do not establish hardware fps targets. Full motion preferences and failure recovery remain EH-06's scope.
