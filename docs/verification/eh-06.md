# EH-06 acceptance evidence

Implemented 2026-11-16. Scope: accessible motion modes (`system`, `full`, `reduced`), keyboard and focus behavior, mobile pointer/resize resilience, 10-second texture load timeout, static no-WebGL affordances, WebGL context-loss pause/recovery/fallback, and shared adaptive-quality / resource-disposal lifecycle.

## Acceptance criteria

| Criterion                                                                                                                         | Implementation and evidence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Motion modes (`System` / `Full` / `Reduced`), persistence, live switching without progress reset                                  | `src/controller.ts` adds `MotionMode`, `resolveReducedMotion`, `setMotionMode`, and `setSystemReducedMotion`. `src/main.ts` persists explicit choices in `localStorage` (`event-horizon.motion`), listens to `prefers-reduced-motion` changes, updates `data-motion` / `data-motion-mode`, and switches modes mid-flight without resetting `elapsed` or `routeKm`. Verified in `tests/accessibility-resilience.spec.ts`.                                                                                                                     |
| Reduced mode disables warp tunnel/FOV, idle spin, digit blur; reduced inertia; <=10 Hz unblurred digits; shared snapshot adapters | `src/controller.ts` zeroes `warp`, reduces flight arc swell (`0.35×`), and scales down fling velocity (`0.2×`, faster `exp(-24*dt)` damping). `src/scenery.ts`, `src/scenery-layers.ts`, `src/renderer.ts`, `src/audio.ts`, and `src/instruments.ts` read `frame.reducedMotion`: streaks/FOV/idle globe/cloud/field/sky/black-hole-time animations disable, audio drive attenuates (`0.5×`), and `RollingDigits` cancels strip animations/blur and throttles active updates to `>= 100 ms` (`<= 10 Hz`). Verified by unit and browser tests. |
| Semantic controls, visible focus, contrast, >=44 px targets, focus transfer, polite announcements                                 | `index.html` and `src/styles.css` enforce `>= 44×44 px` touch targets across visible controls, `:focus-visible` outlines, and non-overlapping layouts across desktop (`1440×1000`), short desktop (`1366×768`), and mobile (`390×844`). `src/main.ts` transfers focus to `Pause` on launch, to `Next` / `Previous` on arrival, to `Return to Earth` on completion, updates `#journey-announcement` politely, and limits speed `aria-label` updates to `>= 1 s` intervals.                                                                    |
| Keyboard inspection, reset, zoom, Escape, dialogs, browser zoom pass-through                                                      | `src/inspection-input.ts` supports Arrow orbit, `+`/`=`/`-`/`_` zoom, `Home`/`0` reset, and skips modified keys (`Ctrl`/`Meta`/`Alt`) so browser zoom shortcuts pass through unhandled. `src/styles.css` applies `overscroll-behavior: contain` on `dialog:modal` and `dialog::backdrop`; `src/main.ts` ignores wheel events while a modal `<dialog>` is open; native `<dialog>.showModal()` handles focus containment and focus restoration on close.                                                                                       |
| Mobile drag/pinch/Next, resize/orientation changes, no overflow or accidental travel                                              | `src/inspection-input.ts` resets pointer state and fling velocity on `pointercancel` / `lostpointercapture`. `window.resize` recomputes renderer/UI framing without altering controller progress. Verified on `390×844` and `844×390` mobile orientation flip with zero horizontal overflow.                                                                                                                                                                                                                                                 |
| Earth-first / adjacent preload, loading status, 10 s timeout fallback without midflight freeze                                    | `src/renderer.ts` defers background `stars` loading to `render()` after initial `setCheckpoint(s.now)`, tracks active `pendingAssets`, exposes `'Loading planetary imagery…'`, and attaches `LOAD_TIMEOUT_MS = 10_000` timers per pending texture that populate the flat fallback texture and notice without blocking flight. Verified with a stalled `moon.jpg` route under controlled clock.                                                                                                                                               |
| No-WebGL mode and WebGL context loss recovery/fallback                                                                            | `src/main.ts` and `src/renderer.ts` disable `#inspection` (`inert`, `aria-disabled`), disable `#zoom-in`/`#zoom-out`/`#reset-view`, and explain static mode in `#inspection-hint` and `#render-status`. `webglcontextlost` pauses playback, clears inspection/wheel state, announces the pause, and displays `Restore 3D view` and `Continue with static illustration` actions. Verified for both recovery and static fallback paths.                                                                                                        |
| Hidden-tab suspension, quality adaptation, repeated navigation disposal, non-blocking errors                                      | `visibilitychange` pauses flight, suspends `AudioEngine`, clears inspection/wheel state, and syncs UI. `setQuality()` scales resolution without altering scientific values/durations; `releaseUnusedTextures` clears pending timers and disposes non-resident textures/nodes on repeated jumps (`earth` -> `jupiter` -> `saturn` -> `neptune` -> `sagittarius-a` -> `earth`).                                                                                                                                                                |

## Limitations and EH-07 handoff

- Headless Chromium runs on ANGLE SwiftShader (software WebGL), so real-GPU frame pacing and physical mobile device touch/audio output remain unmeasured here.
- Context-loss tests validate both real `webglcontextlost` / `webglcontextrestored` handling and synthetic event dispatch in headless SwiftShader.
- Complete combined verification across final planetary/interstellar effects, Voyager/Proxima, Sagittarius A* descent, audio, and reduced-motion/fallback integration belongs to **EH-07**.
